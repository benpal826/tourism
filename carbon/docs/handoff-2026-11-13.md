## 4. 진행 중: "오늘의 종합 요약" 기능 (설계 전 단계)

사용자 요청: 지금 리포트는 분포와 목록뿐이고 결론·인사이트가 없다. 오늘 하루 기사를 종합한 요약과 그 시각화가 필요하다.

지금까지 정해진 것 (설계 문서는 아직 안 씀, 사용자 승인 전):
- **용도:** 아침에 흐름을 파악하고, 중요한 것은 팀에 보고한다. 그래서 보고할 항목에는 근거(공식 문서 링크, 정책 단계, 국내 영향도)가 붙어야 한다.
- **API 키는 쓰지 않는다. 구독 안에서 해결한다.** 기존 `carbon/llm.py` 의 `AnthropicBackend`(API 키 필요) 대신, 구독 로그인된 **Claude Code CLI**(`claude -p --json-schema …`)를 부르는 백엔드를 추가하는 방향(A안)으로 제안했고, 사용자가 로컬 PC 로 옮기기로 하면서 이 방향이 유력. 확정은 아직.
  - 대안: Codex CLI(`codex exec --output-schema`, ChatGPT 구독) / 규칙만.
  - CLI 를 못 쓰는 날(로그인 만료·사용량 소진)은 **규칙 기반 요약으로 자동 대체**해 화면이 비지 않게.
  - 구독 사용량을 아끼려고 **호출을 묶는다**: 하루 종합 요약은 1회 호출, 기사 분류는 50건씩 묶어 몇 회. (지금 설계는 기사 1건 = 1호출, 하루 최대 200)
- **화면 제안 (미확정):** 리포트 맨 위 "오늘의 요약" = 3~5줄 결론 + "보고할 것" 2~3건(공식 문서 근거·링크) + 흐름 그림 1개. 기존 분포·목록은 그 아래 근거로.
- 다음 할 일: 접근 방식 최종 선택 → 짧은 설계 문서(`docs/superpowers/specs/2026-11-13-daily-summary-design.md`) → 사용자 승인 → 구현 계획.
