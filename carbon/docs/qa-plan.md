# 검증 계획서 (4단계)

작성일: 2026-11-11 · 근거: `PRD.md` (4장 기능 F1~F16, 7장 비기능, 8장 성공 지표)

## 읽는 법

- **검증 방법**: `E2E` = Playwright 자동(리포트 화면, `tests/e2e/`), `PT` = pytest 자동(화면 밖), `M` = 수동(사람 판단·실제 환경 필요)
- **결과**: 합격 / 불합격 / 미측정 (+ 근거). 4-2·4-3 을 실행한 뒤 채운다. 최종 판정은 `docs/qa-report.md`.
- 화면 항목(E2E)은 고정 DB `tests/fixtures/sample.db` 로 만든 리포트를 `file://` 로 열어 검증한다. 실제 네트워크·운영 DB 는 쓰지 않는다.
