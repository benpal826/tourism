# 공식 출처 조사 (2-1, 2026-11-03)

F7(정부·공식 출처 수집)을 구현하기 전에 후보 출처의 접속 가능 여부, robots.txt, RSS·API 제공 여부를 확인한 결과입니다.
"확인"은 이번 조사에서 직접 접속해 본 사실이고, "검색 결과"는 웹 검색 요약이라 사이트에서 다시 확인해야 합니다. 이용약관은 한 곳도 읽지 못했으므로 모두 "미확인"입니다.

## 먼저 알아야 할 변화

- **부처 개편으로 이름과 주소가 바뀌었습니다.** (확인)
  - 환경부 → 기후에너지환경부: `www.me.go.kr`은 연결이 거부되고 `www.mcee.go.kr`이 "기후에너지환경부"로 열립니다. (검색 결과는 `me.go.kr`을 안내했으나 직접 접속은 실패. 2025-10-01 출범은 검색 결과)
  - 산업통상자원부 → 산업통상부: `motie.go.kr`이 `motir.go.kr`로 이동합니다.
  - 기획재정부 → 재정경제부: `moef.go.kr`이 `mofe.go.kr`로 이동합니다.
- **정책브리핑(korea.kr)의 RSS는 중단됐습니다.** 공지 "정책브리핑 RSS 서비스 제공 중단 안내"(2026-07-01)가 있고, 추측한 RSS 주소는 모두 404입니다. 공지 본문은 읽지 못했습니다. (확인)
- **국회 의안정보시스템(likms.assembly.go.kr)은 robots.txt가 전체 차단(`Disallow: /`)입니다.** 이 사이트는 수집하면 안 됩니다. (확인)

## 한계

- RSS 링크 탐색은 홈페이지 HTML에서 `rss`, `feed` 문자열을 찾은 것이라, 링크 없이 별도 안내 페이지로만 제공하는 사이트는 놓쳤을 수 있습니다.
- robots.txt는 "접속해도 되는 경로"를 알려 줄 뿐 이용약관과 저작권 조건을 대신하지 않습니다.
- 부처 개편 시점과 새 기관명은 사이트 응답과 검색 결과로만 확인했고 공식 문서로는 확인하지 않았습니다.

## 결정 (2026-11-03)

이용약관이 확인되지 않았지만, 부처 게시판은 **바로 구현**하기로 했습니다. 아래 원칙으로 수집하고, 약관 확인 결과에 문제가 있으면 해당 출처를 끕니다.

- robots.txt를 직접 읽고 허용된 경로만 요청합니다. 읽지 못하거나 거부되면 수집하지 않습니다.
- 같은 사이트에는 2초 간격으로, 목록 첫 페이지만 요청합니다. (하루 1회)
- 제목, 원문 링크, 날짜, 담당 부서만 저장하고 본문과 첨부파일은 가져오지 않습니다.
- 사이트 구조가 바뀌어 글을 0건 찾으면 조용히 넘기지 않고 실패로 기록합니다.

## 남은 일

1. 각 사이트의 저작권·이용약관 확인
2. 열린국회정보 인증키 발급 (사용자 작업. 키는 환경변수로만 사용)
3. 법제처 OpenAPI, EU 기후행동총국, EUR-Lex 조사
4. 사이트 구조가 바뀌면 파서가 깨진다: 매일 실행 로그에서 "목록에서 글을 찾지 못함" 경고를 확인한다
