탄소정책 모니터링 AI Agent 제출 안내

1. 결과보고서.docx
제공된 Word 템플릿의 제목, 항목명, 색상, 표 형식을 유지하고 본문과 스크린샷 3장을 채웠습니다. 제출자 이름이 제공되지 않아 성명 칸은 비워 두었습니다. 제출 전에 성명을 입력하세요.

2. 핵심산출물/index.html
2026-11-13 실제 리포트의 원본 복사본입니다. 브라우저로 바로 열 수 있습니다. CSS와 JavaScript가 포함된 단일 HTML이며 원문 링크를 열 때는 인터넷 연결이 필요합니다.

3. 실행 방법
핵심산출물/source.zip을 별도 작업 폴더에 압축 해제합니다. Windows 11·PowerShell 5.1·Python 3.10 환경에서 먼저 다음을 설정합니다.
$env:PYTHONUTF8='1'
$env:PYTHONIOENCODING='utf-8'
pip install -r requirements.txt
python main.py run

run_daily.bat은 main.py run을 실행하는 수집·리포트용 실행 파일입니다. 이 배치 파일만으로 예약 작업 세션의 AI 분류·요약까지 수행되지는 않습니다. API 키 없이 전체 흐름을 실행하려면 핵심산출물/scheduled-task-prompt.md의 순서를 Claude 앱 예약 작업에 적용합니다. 예약 작업의 작업 폴더와 지시문 경로는 실제 압축 해제 위치에 맞춥니다. 테스트 환경은 requirements-dev.txt와 Playwright Chromium이 필요합니다.

4. 문서와 데이터
CLAUDE.md는 에이전트 작업 지침, README.md는 설치·사용 설명, PRD.md는 기획·요구사항입니다. 이 파일들은 원본 그대로 복사했으며 일부 이전 상태·지표가 남아 있습니다. 결과보고서는 제공된 2026-11-13 실제 실행 결과를 구분해 기록했습니다.
샘플데이터/README.txt에서 테스트용 고정 데이터와 실제 AI 입력·출력 파일을 구분해 설명합니다. source.zip에는 main.py, config.py, carbon/, tests/, requirements*.txt, run_daily.bat이 들어 있고 __pycache__, data/, reports/, logs/, work/는 제외했습니다.

5. 스크린샷의 출처
01_에이전트_시작.png: 실제 예약 작업 지시문 원문을 웹 페이지로 렌더링해 Playwright로 캡처했습니다.

위 두 이미지는 Claude 데스크톱 앱의 직접 스크린샷이 아닙니다. 필요하면 실제 앱 화면으로 교체할 수 있습니다.

6. 확인 범위와 제출
복사본 해시, ZIP 내용, 템플릿 항목명·페이지 설정 보존, 이미지 3장 삽입을 확인했습니다. 원본 프로그램·테스트는 수정하지 않았으며 커밋·푸시하지 않았습니다. pytest 533개 통과는 제공된 프로젝트 검증 결과이며 이번 제출물 작성 중 재실행한 수치가 아닙니다.
문서의 실제 페이지 렌더링 검수는 완료하지 못했습니다. 기본 렌더러는 LibreOffice 부재로 실패했고 Word 자동화는 승인 단계에서 차단됐습니다. 제출 전에 Word에서 페이지 나눔과 이미지 배치를 확인하세요.
최종제출물.zip은 이 안내, 결과보고서, 핵심산출물, 샘플데이터, screenshots를 묶은 파일입니다. 성명 입력 또는 앱 스크린샷 교체 시 압축 파일도 갱신하세요. 템플릿의 제출 이름 규칙은 [현대제철_AI에이전트]_성명_최종결과물.zip입니다. 외부 전송은 수행하지 않았습니다.
